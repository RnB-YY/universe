一个持续生长的个人知识系统，收录课程发表、研究资料、视觉作品与作品集。关注景观、生态、翻译与公共空间。

网站：<https://heixiong.vip>（GitHub Pages，`main` 分支根目录）

## 星系入口

`universe/` 是网站主页。访问根目录会自动跳转到这里。

主页的星空由 `universe/cosmos.js` 用 WebGL 实时渲染（无第三方依赖）：四颗行星沿各自椭圆轨道持续公转，轨道、周期、颜色都在文件开头的 `PLANETS` 配置里调整。行星本身仍是普通按钮，不支持 WebGL 的浏览器会自动切换到简化版本。

点击行星进入三级空间结构：

1. **星系总览**（`cosmos.js`）：选择行星。
2. **行星观测**（`worlds.js`）：行星占据画面并缓慢自转，表面的信号点固定在真实经纬度上，随行星转到背面时隐藏；可拖动旋转。
3. **区域环境**（`worlds.js`）：点击信号点后镜头降落到该区域，显示该分类下的项目。

每颗行星的生态规则（配色、地质、大气、运动）和它的区域都写在 `universe/worlds-data.js`，每个区域对应 `app.js` 里一个真实分类。区域地貌由配置生成着色器，不需要额外图片。每一级都有独立地址，例如 `#/bloom/tidal-mirror`，可直接链接或刷新。
